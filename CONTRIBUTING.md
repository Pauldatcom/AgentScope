# Contributing

## Branches
- `main` is protected.
- Feature branches: `feat/<scope>-<short>` (e.g. `feat/import-usecase`).
- Fixes: `fix/<short>`.

## Pull requests
- Every change goes through a PR linked to an issue.
- At least one reviewer from another group must approve before merge.
- CI (ruff, mypy, pytest, web build) must be green.

## GitHub Projects
- Board columns: **Prévu** / **En cours** / **Revue** / **Terminé**.
- Move your issue to **En cours** when you start, to **Revue** when the PR is open,
  to **Terminé** when merged.

## Commits
- Conventional style: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
- Keep commits small and focused.

## AI usage
- AI assistance is expected; you remain responsible for correctness.
- Never commit secrets or API keys.
- Never execute code generated by an AI model at import time — mappings are
  applied by the deterministic engine only.
