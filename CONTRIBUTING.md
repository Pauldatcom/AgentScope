# Contributing

## Branches

- `main` is protected (1 approving review + CI must pass + linear history).
- Feature branches: `feat/<scope>-<short>` (e.g. `feat/import-usecase`).
- Fixes: `fix/<short>`.
- Documentation: `docs/<short>`.

## Pull requests

- Every change goes through a PR linked to the issue(s) it closes.
- At least one reviewer must approve before merge.
- CI (ruff, mypy, pytest, web build) must be green.
- Squash-merge is preferred.

## GitHub Projects

- Board: [AgentScope Sprint](https://github.com/users/Pauldatcom/projects/1).
- Columns: **Prévu** / **En cours** / **Revue** / **Terminé**.
- Move your issue to **En cours** when you start, to **Revue** when the PR is
  open, to **Terminé** when merged.

## Commits

- Conventional style: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
- Keep commits small and focused.
- Reference the issue number in the body: `Closes #42`.

## Adding a new data source

1. Import the file via `POST /imports/upload` or the UI assistant.
2. If the structure is unknown, use the AI assistant (`/assistant` page) to
   propose a mapping. Edit, preview, validate.
3. The mapping is saved in the `mapping` table (versioned, reusable).
4. No code change is needed — the import engine is driven by configuration.
5. Document the mapping in `docs/mappings.md`.

## Adding a new AI provider

1. Implement `MappingAgentPort` in `agentscope/adapters/ia/<provider>/`.
2. Wire it in `agentscope/api/main.py::_build_mapping_agent`.
3. Add the provider to `.env.example` and `docs/ai_providers.md`.
4. No changes to `domain` or `application` are required.

## Running tests

```bash
# Unit + e2e (no Postgres, no network)
uv run pytest tests/unit tests/e2e -v

# Integration (requires Postgres via docker compose up -d postgres)
uv run pytest -m integration -v

# Lint + type check
uv run ruff check .
uv run mypy agentscope
```

## AI usage

- AI assistance is expected; you remain responsible for correctness.
- Never commit secrets or API keys.
- Never execute code generated by an AI model at import time — mappings are
  applied by the deterministic engine only.
- The AI proposes; the engine applies. See `docs/decisions.md` (ADR-002).
